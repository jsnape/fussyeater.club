# Landing Page

> Route: `/` (unauthenticated visitors)

## Purpose

Convert first-time visitors (parents/caregivers of fussy eaters) into registered users. Communicate the core value proposition and build trust quickly.

---

## Page Sections (top to bottom)

### Announcement Bar

- Full-width bar above navigation
- Single line of welcome/promotional copy
- Dismissible (optional)

### Navigation (Landing variant)

- Logo (icon + wordmark) on the left
- Anchor links: "How it Works", "Sample Recipes", "Stories"
- Right side: "Log In" text button + "Create Account" primary action button
- Sticky on scroll

### Hero Section

- Two-column layout on desktop (text left, image right); stacks on mobile
- **Left column:**
  - Category badge/pill (e.g. "For Caregivers")
  - Headline (large, expressive) — focus on the emotional outcome, not features
  - Supporting paragraph — briefly explain allergy-aware planning + sensory preferences
  - Two CTAs: primary "Start Your Free Plan" + secondary "Browse Sample Recipes" (with arrow icon)
  - Social proof line: avatar stack (3 user photos) + "Joined by X+ relieved parents"
- **Right column:**
  - Large hero image (sensory-friendly meal)
  - Two floating badge overlays on the image:
    - "Sensory-Friendly" badge with icon + subtitle "Texture & color filters"
    - "Allergy-Aware" badge with icon + subtitle "Strict ingredient tracking"

### Social Proof / Trust Quote

- Centred editorial-style quote (testimonial)
- Row of publication/media logos below the quote (greyscale, colour on hover)

### How It Works (Value Propositions)

- Section heading + supporting paragraph
- 3-column grid of feature cards (single column on mobile):
  1. **Granular Filtering** — icon, title, description about filtering by texture/colour/temperature
  2. **Low-Pressure Planning** — icon, title, description about flexible weekly menus
  3. **Smart Shopping Lists** — icon, title, description about auto-generated categorised grocery lists
- Each card: centred icon in a circular container, heading, body text

### Sample Recipe Gallery

- Section heading + supporting paragraph
- 4-column responsive grid of recipe cards (2-col tablet, 1-col mobile)
- Each card:
  - Image with hover zoom effect
  - Overlay badges for texture type (e.g. "Smooth", "Crunchy") and dietary info (e.g. "Dairy-Free")
  - Recipe name below image
  - Subtitle with texture/serving style descriptors
- "View Full Recipe Library" button centred below grid

### Testimonials

- Section heading
- 2-column grid of testimonial cards (stack on mobile)
- Each card:
  - Quote mark icon (decorative)
  - Testimonial paragraph text (italic)
  - Author row: avatar photo, name, subtitle (relationship/context)

### Final CTA / Registration

- Full-width call-to-action section
- Heading + supporting paragraph
- Inline registration form card (centred):
  - Email input
  - Password input
  - "Sign Up" submit button
  - "Already have an account? Log in" link

### Footer

- Logo
- Tagline text
- Links: Privacy Policy, Terms of Service, Contact Support
- Copyright notice

---

## Key Interactions

- Announcement bar can be dismissed (closes with no animation or fade out)
- Navigation becomes sticky when scrolled past hero
- Hero CTAs link to registration or recipe browse
- Recipe gallery cards navigate to recipe detail on click
- Trust logos transition from greyscale to colour on hover
