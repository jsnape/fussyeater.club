# Ideas & Future Enhancements

Items to revisit later. Not planned for immediate implementation.

## Recipe Editing UX

- **Drag-and-drop reordering for ingredients** — allow users to reorder ingredients via drag-and-drop in edit mode (add/remove first, drag later).
- **Drag-and-drop reordering for method steps** — same as ingredients.
- **Inline editing of individual ingredients** — click an ingredient row to edit it in-place rather than remove-and-re-add.
- **Section-by-section PATCH saves** — allow saving individual recipe sections independently instead of the whole recipe. Adds complexity around partial-update edge cases.
